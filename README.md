# SillyTavern Group Member Index Macro

グループチャットのメンバー一覧の並び順（上から 1, 2, 3…）に従って、`{{group::番号}}` をキャラクター名に変換する SillyTavern 拡張機能です。

## 使い方

グループの並び順が以下の場合：

1. アリス
2. ボブ
3. キャロル

| マクロ | 変換結果 |
| --- | --- |
| `{{group::1}}` | アリス |
| `{{group::2}}` | ボブ |
| `{{group::3}}` | キャロル |
| `{{group}}` | アリス, ボブ, キャロル |

## 仕様

- **自動更新**: メンバーの並べ替え・追加・削除は、次回マクロが評価されたときに反映されます（評価のたびに現在のメンバー一覧を参照します）。
- **ミュート**: ミュート中のメンバーも番号を維持します。
- **番号**: 1 始まり。`0`、範囲外、数値以外は空文字列になります。
- **互換性**: 引数なしの `{{group}}`（および別名 `{{charIfNotGroup}}`）は本体の従来動作をそのまま使います。
- **適用範囲**: キャラクターカード、Lorebook、プロンプトなど、通常のマクロ展開が行われる箇所すべて。
- **グループチャット限定**: 番号指定はグループチャットでのみ動作します。`{{char}}` との 1 対 1 の会話では `{{group::番号}}` は変換されず、`{{group::番号}}` のまま残ります（引数なしの `{{group}}` は本体どおりキャラクター名を返します）。

## マクロエンジンについて

- **新マクロエンジン**（既定で有効の "Experimental Macro Engine"）: 組み込みの `{{group}}` を、任意の番号引数を受け付ける形で置き換えます。番号に上限はありません。
- **旧マクロエンジン**: 引数付きマクロに対応していないため、`{{group::0}}` ～ `{{group::50}}` を個別のマクロとして登録します。起動時に旧エンジンの場合、または設定で旧エンジンへ切り替えた時点で登録されます。

## インストール

SillyTavern の「Extensions」→「Install extension」に、このリポジトリの URL を入力してください。

```
https://github.com/GenesisOmniarch/SillyTavern-GroupIndex
```
